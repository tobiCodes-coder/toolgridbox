PDF page number adder

Add page numbers to a PDF file. Nothing leaves your browser.

How to use this tool
Upload a PDF, choose where the numbers should appear and how they should look, then click "Add page numbers". A new copy of the file will download automatically — your original file is never modified or uploaded anywhere.
⚠ Existing page numbers or footer text won't be removed — the new number will be added on top. Check the position doesn't overlap with your existing content.
