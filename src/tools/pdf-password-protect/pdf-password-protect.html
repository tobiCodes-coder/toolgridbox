PDF password protect

Add a password to a PDF file. Nothing leaves your browser.

How to use this tool
Upload a PDF file, type the password you want to protect it with, then click "Protect PDF". A new, encrypted copy of the file will download automatically — your original file is never modified or uploaded anywhere.
⚠ Don't forget this password — if you lose it, the protected PDF cannot be opened again. This tool cannot recover it for you.
