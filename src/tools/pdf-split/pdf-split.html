PDF split

Split a PDF into individual pages, or extract a specific page range.

How to use this tool
Upload a PDF file. Choose "Split every page" to get each page as a separate PDF, or "Extract range" to pull out specific pages (e.g. 2-5). Then download the result.
⚠ Password-protected PDFs are not supported. Please remove the password before uploading.
